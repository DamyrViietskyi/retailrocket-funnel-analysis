# Retailrocket Funnel Analysis

**Stack:** Python · pandas · Jupyter

How does shopping conversion change over time?

## Analysis

Deduplicate shopping events and use visitor-level and visitor-item metrics to study conversion and returning visitors.

## Run locally

Install dependencies with `python -m pip install -r requirements.txt`. Place authorized copies of the input files at: data/events.csv.gz. Open `analysis.ipynb` in Jupyter and run it from the repository root. Input datasets are excluded.

Developed from STAT163 coursework at Kyiv School of Economics.
